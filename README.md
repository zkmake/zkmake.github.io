# zkmake.github.io

The root of zkmake's GitHub Pages host. It serves only `robots.txt`, because crawlers read that file
at the host root and nowhere else; it points them at the project sites' sitemaps.

`.nojekyll` keeps this README from being published as the root page.

To add a project site's sitemap, add a `Sitemap:` line to `robots.txt`.
